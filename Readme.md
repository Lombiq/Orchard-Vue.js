## About

This project contains modules related to using [Vue.js](https://vuejs.org/) in [Orchard Core](https://orchardcore.net/).

- [Lombiq.VueJs.Resources](Lombiq.VueJs.Resources/Readme.md): adds Vue.js packages to the Orchard Core resource manager in the form of [JavaScript modules](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Modules).
- [Lombiq.VueJs](Lombiq.VueJs/Readme.md): (⚠️ deprecated) Vue.js Single File Component compiler for Orchard Core.

Do you want to quickly try out this project and see it in action? Check it out in our [Open-Source Orchard Core Extensions](https://github.com/Lombiq/Open-Source-Orchard-Core-Extensions) full Orchard Core solution and also see our other useful Orchard Core-related open-source projects!
